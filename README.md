# Simple Face Recognition Project

A lightweight face recognition system built using Python and OpenCV. This project demonstrates how to detect and recognize faces in real-time using a webcam or image input.

## 🧠 Features

* Face detection using Haar Cascades or Dlib
* Face recognition using `face_recognition` library
* Real-time webcam support
* Image-based recognition support
* Simple UI using OpenCV display window



## Required Libraries

* `face_recognition`
* `opencv-python`
* `numpy`

## Run the Recognition System

```bash
python main.py
```

This will start your webcam and identify faces in real time.
